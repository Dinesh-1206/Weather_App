# 🌤️ Weather App

A simple, responsive, and user-friendly **Weather App** built using **HTML, CSS, and JavaScript**. The application uses the **WeatherAPI** to fetch real-time weather information for any city.

Users can search for a city and instantly view its current temperature, weather condition, humidity, wind speed, feels-like temperature, and weather icon.

## 🚀 Live Demo

🔗 **Live Demo:**https://weather-app-ec1y.vercel.app/

## 📌 Features

* 🔍 Search weather by city name
* 🌡️ Display current temperature in Celsius
* 🌤️ Show current weather condition
* 💧 Display humidity
* 💨 Display wind speed
* 🌡️ Display feels-like temperature
* 🖼️ Dynamic weather icons
* ⚡ Real-time weather data
* 📱 Responsive and clean user interface
* ❌ Error handling for invalid city names
* ⏳ Loading message while fetching weather data

## 🔗 API Used

This project uses **WeatherAPI** to retrieve current weather information.

The API provides information such as:

* City and country
* Temperature
* Weather condition
* Humidity
* Wind speed
* Feels-like temperature
* Weather icon

## ⚙️ How It Works

1. User enters a city name.
2. JavaScript reads the entered city.
3. The application sends a request to WeatherAPI.
4. WeatherAPI returns the current weather data.
5. JavaScript processes the response.
6. The weather information is displayed on the webpage.

## ☁️ Deploy on Vercel

This project can be deployed easily using Vercel.

### Steps:

1. Create a free account on Vercel.
2. Select **Add New Project**.
3. Import the GitHub repository:

```text
Dinesh-1206/Weather_App
```

4. Vercel will automatically detect the project.
5. Since this is a simple HTML/CSS/JavaScript project, no build command is required.
6. Click **Deploy**.
7. After deployment, Vercel will provide a live URL.

Example:

```text
https://weather-app-example.vercel.app
```

Add your actual Vercel URL in the **Live Demo** section above.
